# /kernel — Сердце KVP

Священная папка, содержащая ядро протокола KVP.

## Содержание
- wallet.py — священный кошелёк (v0.2, с сохранением в JSON)
- config.json — конфигурация ядра

## Архитектура
- Криптография: ECDSA (secp256k1), SHA-256, RIPEMD-160
- Хранение: JSON-файлы (wallets.json, ledger.json)
- В будущем: постквантовая криптография (Kyber, Dilithium)
