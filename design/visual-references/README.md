# Visual Reference Lab

Рабочая область для визуальных референсов NetCity KVP. Здесь мы не просто
сохраняем картинки, а разбираем каждый образец на наблюдаемые составляющие и
переводим их в правила интерфейса, design tokens и проверяемые React/CSS-задачи.

## Структура

| Папка | Назначение |
| --- | --- |
| `00-inbox/` | новые материалы до разбора и атрибуции; |
| `01-approved/` | референсы, выбранные для работы; |
| `02-breakdowns/` | разбор композиции, слоёв, поведения и доступности; |
| `03-tokens/` | извлечённые цвета, типографика, spacing, elevation и motion tokens; |
| `04-exports/` | производные wireframes, moodboards и implementation notes. |

Каждая единица работы оформляется отдельной папкой:

```text
REF-YYYY-MM-DD-short-name/
├── source.md       # источник, автор, лицензия/разрешение, дата и viewport
├── observation.md  # что действительно видно; без догадок о реализации
├── breakdown.md    # декомпозиция на слои и поведение
├── tokens.json     # извлечённые или предложенные design tokens
├── source/         # исходный референс, если его можно хранить в репозитории
└── derived/        # наши схемы, wireframes и варианты
```

## Правила разбора

1. Сначала фиксируем происхождение материала и право на его использование.
2. Отделяем наблюдение от интерпретации: `observation.md` не содержит
   предположений о фреймворке, исходном CSS или внутренней архитектуре.
3. Разбираем образец по слоям: canvas, grid, shell, navigation, content,
   controls, states, typography, color/material, motion и responsive behavior.
4. Каждый вывод связываем с целевым surface или компонентом NetCity KVP.
5. Производный код, скриншоты и токены помечаем как `derived`, чтобы не путать
   оригинальный референс с нашей реализацией.

## Безопасность и лицензии

- Не добавляй сюда API-ключи, cookies, приватные макеты или персональные данные.
- Для внешних материалов обязательно укажи URL, автора/правообладателя,
  лицензию или основание разрешения в `source.md`.
- Если материал нельзя коммитить, храни только ссылку, собственные заметки и
  созданную нами декомпозицию.
- SVG, шрифты и изображения проходят обычный review перед включением в EXE.

## Быстрый старт

Скопируй [`REFERENCE_TEMPLATE.md`](REFERENCE_TEMPLATE.md) в новую папку
`01-approved/REF-YYYY-MM-DD-short-name/`, затем добавь запись в
[`manifest.json`](manifest.json). Пустые каталоги удерживаются `.gitkeep`, пока
в них не появится первый референс.
