# Карта потенциальных патентных семейств

Статус: гипотезы для патентного поиска, не утверждение новизны.

## Семейство A — KVP protected command fabric

Идентифицированные сессии, capability-aware авторизация, долговременная
идемпотентность команды, неопределённый результат и согласование состояния в
гетерогенном парке. Основное раскрытие находится в
[досье KVP](kvp-invention-disclosure-ru.md).

## Семейство B — Architect OS graph compiler

Преобразование версионированного многослойного графа моделей, инструментов,
политик и границ данных в детерминированный план управляющих воздействий с
проверкой capabilities, blast radius, бюджетов и доказательств до исполнения.

Требуется отделить техническую компиляцию/развёртывание от правил хозяйственной
или интеллектуальной деятельности и показать технический результат на
вычислительной системе.

## Семейство C — Fleet reconciliation

Декомпозиция пакетного изменения парка в индивидуально идентифицируемые операции,
остановка по доказуемым условиям, сохранение частичных/неопределённых состояний и
построение плана согласования без повторного воздействия.

## Семейство D — Evidence-bound model routing

Выбор локального или облачного модельного endpoint по capability, классификации
данных, доверительному уровню и свежести evidence с фиксацией версии решения и
последующим доказательством фактического маршрута.

## Семейство E — Appliance trust and recovery

Связывание измеренного состояния NetCityOS Appliance, подписанной версии
архитектуры, KVP-команд и recovery/rollback так, чтобы после сбоя сохранялась
проверяемая непрерывность управляющего состояния.

## Семейство F — Engine/cache attestation

Отдельный исследовательский трек. Подача возможна только после точного определения
объекта состояния, источника измерения, модели атак, механизма свежести и
экспериментальной проверки. Нельзя строить заявку на подписи произвольных байтов
или недоступном API движка.

## Порядок работы

1. Поиск патентов и непатентной литературы отдельно по каждому семейству.
2. Карта признаков: источник уровня техники, отличие, технический результат.
3. Решение о единстве/разделении заявок и приоритетном семействе.
4. Выбор признаков для патента и для сохранения как ноу-хау.
5. Экспериментальное подтверждение и достаточное раскрытие.
6. Международная стратегия только после определения рынков, бюджета и сроков.
