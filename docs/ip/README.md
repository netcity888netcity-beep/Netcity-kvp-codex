Статус: конфиденциальная рабочая документация, не готова к подаче без проверки
патентным поверенным и юристом ООО «НетСити».

## Назначение

Этот каталог превращает технические материалы проекта в управляемый пакет для
правовой охраны. Он не устанавливает патентоспособность и не заменяет документы,
оформленные специалистом по итогам поиска уровня техники.

## Критическое правило

До решения о подаче заявки техническое раскрытие, формула, схемы и отличительные
признаки не публикуются, не отправляются потенциальным партнёрам без NDA и не
выносятся в публичный репозиторий. Наличие льготных периодов в отдельных
юрисдикциях не используется как рабочая стратегия сохранения новизны.

## Реквизиты, которые необходимо подтвердить

- точное полное и сокращённое наименование юридического лица;
- ИНН, ОГРН, юридический адрес и подписант;
- состав авторов программ и изобретателей по каждому результату;
- основание принадлежности исключительных прав ООО;
- даты создания, служебные задания, акты и история раскрытий;
- страны и рынки, где требуется охрана.
