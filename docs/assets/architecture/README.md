# NetCity Architecture Illustrations

This directory stores approved visual architecture assets for the NetCity project.

## Asset conventions

- Keep approved originals unchanged.
- Use descriptive, versioned filenames.
- Link each image from its corresponding architecture specification.
- Add new versions as new files; do not overwrite historical approved assets.
- Treat illustrations as explanatory artifacts, not as proof that a design is implemented.

## Trust Root

### Owner Recovery Ceremony v0.1

Planned asset filename: `owner-recovery-ceremony-v0.1.png`

Status: the generated image has been prepared as a PNG, but this GitHub connection currently exposes text-file and Git-object operations without a binary-file handoff from the generated image attachment. The image itself is therefore not yet committed. Do not treat the planned filename as an existing repository asset.

The architecture represented by this illustration is a proposal: owner verification, C4 technical verification, a 3-of-4 quorum from C2–C5, provisioning of a new C1 share, revocation of the old C1 share, and restoration of Root Authority control.
