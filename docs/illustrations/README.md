# NetCity illustrations and diagram sources

This directory is the canonical home for NetCity visual assets and editable engineering diagrams.

## Editable diagram sources committed

- `NETCITY_RUNTIME_TOPOLOGY.mmd` — target system topology and boundaries.
- `DEVICE_TRUST_AUTHORIZATION.mmd` — Hybrid Trust, Device Identity and KVP authorization flow.
- `COMPUTE_NODE_POWER_THERMAL.mmd` — target compute node component/power/thermal boundary.
- `ZONT_FIELD_INTEGRATION.mmd` — user-reported boiler-control case and proposed NetCity bridge boundary.

These Mermaid files are source diagrams, not proof of implementation. All target components are marked as proposed/planned where appropriate.

See `docs/memory/NETCITY_PROJECT_STATE_2026-11-27.md`, section 12, for the curated Library asset inventory. Original raster/GIF files are not marked as uploaded until their bytes are present in this directory and verified in GitHub.

When transferring originals:
1. Preserve source bytes and original filenames where practical.
2. Place project diagrams in this directory; place broad concept art in `concepts/` and technical schematics in `engineering/` if the directory is later subdivided.
3. Do not include personal photos, unrelated screenshots, credentials, account identifiers or private data.
4. Add a caption/description and identify whether each asset is approved brand material, concept art, or a technical design proposal.
5. Verify the GitHub file URL and commit SHA before updating the memory status to uploaded.
